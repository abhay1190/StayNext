# StayNexa

StayNexa is a modern full-stack vacation rental platform built with the MERN stack (MongoDB, Express.js, React, and Node.js). It enables users to discover unique accommodations, list their own properties, and manage bookings through a clean and responsive interface.

## Features

- 🔐 Secure User Authentication
- 🏠 Property Listing & Management
- 📷 Image Uploads
- 🔍 Search & Filter Listings
- ❤️ Wishlist/Favorites
- ⭐ Reviews & Ratings
- 📱 Fully Responsive Design
- ⚡ RESTful API
- ☁️ Cloudinary Image Storage
- 🔒 JWT Authentication

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Cloudinary
- Tailwind CSS / CSS
